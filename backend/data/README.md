# `backend/data` — данные времени выполнения

Здесь лежит SQLite-файл приложения. **Это не исходный код**, а runtime-хранилище.

## Файлы

- **`portfolio.db`** — локальная база (заявки, отзывы). Создаётся/обновляется при старте API (`app.database`). В Docker монтируется том `/app/data`.

Не коммитьте секреты и продовые дампы сюда без необходимости. Бэкапы на VPS — скрипт [`../../deploy/backup.sh`](../../deploy/backup.sh).
