# `public/assets` — изображения логотипов

PNG-файлы технологий и соцсетей (`python.png`, `fastapi.png`, `telegram.png`, `hh.png` …).

Подключаются через `shared/lib/assetUrl` и `entities/tech/TechLogo` / виджет Contacts. Имена файлов должны совпадать с ключами в `shared/content/stack.ts` и конфиге контактов.
