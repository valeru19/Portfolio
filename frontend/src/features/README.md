# `features` — пользовательские сценарии

Слой FSD с законченными действиями: навигация по спирали, формы, смена темы/языка, копирование email.

## Фичи

| Фича | Папка |
| --- | --- |
| Спиральная навигация | [`section-navigation/`](section-navigation/README.md) |
| Заявка | [`submit-application/`](submit-application/README.md) |
| Отзыв | [`submit-review/`](submit-review/README.md) |
| Копирование email | [`copy-email/`](copy-email/README.md) |
| Язык | [`switch-language/`](switch-language/README.md) |
| Тема | [`switch-theme/`](switch-theme/README.md) |

Виджеты подключают UI фич; `App` / `SpiralNav` поднимают провайдер спирали.
